# GeneratePress Child Theme

This is a child theme for the [GeneratePress](https://generatepress.com/) WordPress theme. The child theme allows you to customize the appearance and functionality of GeneratePress without affecting the parent theme.

## Features
- Inherits all functionality and styling from the GeneratePress theme.
- Add your own customizations without affecting the parent theme.

## Installation

1. **Download the Child Theme:**
   Clone or download the child theme files from this repository.

   ```bash
   git clone https://github.com/kahnu044/generatepress-child.git
   ```

2. **Upload to WordPress:**
   - Upload the `generatepress-child` folder to your `wp-content/themes` directory.

3. **Activate the Child Theme:**
   - Log in to your WordPress dashboard.
   - Go to **Appearance > Themes** and activate the "GeneratePress Child" theme.

4. **Customize:**
   - You can now add custom styles or modify theme files without altering the parent theme.

## Customization
- Add your custom CSS in the `style.css` file or you can use `main.css`.
- Use the `functions.php` file to add additional functionality to the child theme.
